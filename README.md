這是一款使用 Unity 開發的 AVG 視覺小說互動敘事遊戲 Demo。

👉 **[[點擊這裡下載最新 Demo 版 (ZIP檔](https://github.com/feach89/VirtualLove_Demo/releases/tag/v1.0.0

## **遊戲概念**
2072年複製人的議題已經充斥在社會議題當中，你沒辦法預料你身邊親密的人在何時被取代，身為按摩師的你除了在日復一日的工作之外，也尋求著與顧客之間發展更加親密的關係，但複製人的威脅卻悄悄的在逼近你身邊，你該如何拯救心愛之人免於複製人的觸手之下呢……
